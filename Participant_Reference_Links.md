| Labs | Framework / Platform | Main Concepts |
|---|---|---|

| 10-12 | AutoGen | Assistant agents, group chat, reviewer-validation, autonomous task solving |
| 13, 13A, 14, 15 | OpenAI + ChromaDB | Agentic RAG, query decomposition, hybrid search, separate vector stores |
| 16-18 | Semantic Kernel | Plugins, semantic functions, native functions, orchestrated workflows |

| 21 | GitHub Actions | Prompt versioning, AI CI/CD, deployment validation |
| 22 | Microsoft Foundry | Agent-driven workflows, Foundry concepts |
| 23 | Streamlit + LangGraph + RAG | End-to-end enterprise agentic AI capstone with UI |
